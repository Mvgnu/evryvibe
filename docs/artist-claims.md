# Artist claims and event submissions

Artists follow @evryvibe and DM `CLAIM`. The Meta webhook at `/api/instagram/webhook` verifies the app signature and business recipient, requests the sender's Instagram username and follow state, matches the unique catalogue profile, and sends a short-lived claim link. The link carries its token in the URL fragment so it is not sent in ordinary HTTP requests; a deliberate form submission exchanges it for an HttpOnly session. A claimed DJ can manage their bio and labelled HTTPS or mailto links, and create events with a cover. Artist-owned profile edits are kept apart from agent-managed fields.

Setup requires an Instagram professional account, a Meta application, messaging permissions, webhook subscription, public HTTPS callback, app secret, verification token, account ID, access token, Graph API version and a separate random claim token secret. See `ops/production.env.example`. The claim button stays hidden until the configuration exists. Validate app review/permissions and live `username,is_user_follow_business` response with a real test account before activation. Do not print access tokens or claim links in logs. Existing unclaimed or unmatched accounts need an alternate support path.

Venue searches query the public Nominatim service only after an artist explicitly requests a search; the database caches results and limits uncached application requests to one per 1.1 seconds. The endpoint can be replaced using `EVRYVIBE_GEOCODER_URL`. Only public venue addresses should be submitted, and OSM attribution is shown. The public service is capacity-limited; see https://operations.osmfoundation.org/policies/nominatim/ and use another service when needed. Artist-confirmed search results are validated against the cache before saving. Cover files are decoded, size/pixel limited, re-encoded as WebP, stored in PostgreSQL and served from a same-origin endpoint; backup size grows with covers.

`EVRYVIBE_DEMO=1` exposes `/artist/preview` locally with clearly fictional examples. It does not save or publish. A passing simulated webhook or preview does not demonstrate live Instagram access.
